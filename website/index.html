GoogleFontsKMP

Runtime Google Fonts for Compose Multiplatform — Android, iOS, Desktop.

Android · iOS · Desktop

Quick start

@Composable
fun Greeting() {
    val roboto = rememberGoogleFontFamily(GoogleFont("Roboto"), weight = FontWeight.Bold)
    Text(text = "Hello, Google Fonts!", fontFamily = roboto)
}

Why GoogleFontsKMP?

  • Offline-first — fonts are cached in memory and on disk after the first load.
  • Drop-in AndroidX API — mirrors ui-text-google-fonts.
  • No build-time downloads — fonts load at runtime.
